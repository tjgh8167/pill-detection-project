# Contribution

## 역할 요약

이 프로젝트에서 저는 PM과 Data Engineering 역할을 함께 맡았습니다. 팀장으로 협업 구조를 잡고, 데이터 전처리부터 학습 실행, 제출 파일 생성까지 이어지는 파이프라인이 끊기지 않도록 관리했습니다.

## 담당한 주요 파일

| 파일 | 담당 내용 |
| --- | --- |
| `src/dataloader.py` | 데이터 무결성 검사, JSON annotation 탐색, YOLO label 변환, train/val split, 소수 클래스 증강 |
| `main.py` | 전처리, 모델 생성, 학습, 평가, 예측 저장을 연결하는 전체 실행 파이프라인 |
| `submission.py` | YOLO 예측 결과를 Kaggle 제출 CSV 형식으로 변환 |

## 협업 기여

- GitHub repository와 작업 흐름을 구성했습니다.
- 팀원별 역할을 PM, MA, EL로 나누고 작업 범위를 정리했습니다.
- 데일리 스크럼과 협업일지를 통해 진행 상황을 관리했습니다.
- 코드와 실험 결과가 흩어지지 않도록 실행 파일, 노트북, 문서 구조를 관리했습니다.
- 최종 발표 자료를 공동 제작하고, 발표 후 질의응답을 담당했습니다.

## 핵심 경험

이 프로젝트에서 가장 크게 배운 점은 AI 모델 성능이 모델 구조나 하이퍼파라미터만으로 결정되지 않는다는 점입니다. 점수가 0.95점대에서 정체되었을 때, 학습 데이터와 annotation의 연결 상태를 다시 확인했고, 누락 데이터를 제거한 뒤 파이프라인을 안정화했습니다.

이 경험은 실제 AI 엔지니어 업무에서도 중요한 문제 해결 방식이라고 생각합니다. 모델을 학습시키는 것에서 끝나지 않고, 데이터가 신뢰할 수 있는지와 결과가 제출 또는 서비스 형식에 맞게 이어지는지를 함께 확인해야 하기 때문입니다.
